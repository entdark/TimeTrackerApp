# Time Tracker App
An iOS mobile application for tracking tasks time.

## Public beta testing downloads:
1. Install TestFlight on your iOS device: https://apps.apple.com/app/testflight/id899247664  
2. Then open that link on your iOS device: https://testflight.apple.com/join/2pg9CvGg

## Features
- Creating tasks
- Creating projects
- Tracking tasks time
- Editing tasks
- Live Activity for continuous background usage

## Frameworks
- SwiftUI
- Combine
- SwiftData
- ActivityKit
