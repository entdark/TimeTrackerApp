# Time Tracker App
An iOS mobile application for tracking tasks time.

## Features
- Creating tasks
- Creating projects
- Tracking tasks time
- Editing tasks
- Live Activity for continuous background usage

## Frameworks
- SwiftUI
- Combine
- SwiftData
- ActivityKit
